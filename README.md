## Features

Drag blocks from JEI into any of Scannable Reforged's five scanner slots while preserving empty slot positions.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.0 or newer
- [Scannable Reforged](https://www.curseforge.com/minecraft/mc-mods/scannable-reforged) 1.1.2 or newer
- JEI 19 or newer

## Building

```bash
./gradlew build
```

The built mod is written to `build/libs/`.
